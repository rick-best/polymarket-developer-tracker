# Official Engagement Workflow

Last updated: 2026-05-25

Goal: use daily Polymarket search/intelligence results to move this account into the official developer orbit through useful public work, not fake activity.

## Daily Loop

1. Run official source checks:
   - `npm run community:intel`
   - `npm run site:portfolio`
   - `npm run site:engagement`
   - `npm run verify`
2. Review `site/engagement/index.html`.
3. Pick one GitHub candidate from official Polymarket repos.
4. Reproduce or research locally using read-only or dry-run steps.
5. Prepare one of:
   - a GitHub issue comment draft,
   - a new issue draft,
   - a documentation fix,
   - a small PR patch,
   - an X build update draft.
6. Ask the user before posting, commenting, submitting a PR, pushing to a public repo, or tagging official X accounts.
7. Record the outcome in the local project status and evidence trail.

## Official Surfaces

- Builders Program: `https://builders.polymarket.com/`
- Builder profile: `https://polymarket.com/settings?tab=builder`
- Official GitHub: `https://github.com/Polymarket`
- Docs index: `https://docs.polymarket.com/llms.txt`
- Builders X: `https://x.com/PolymarketBuild`

## Contribution Strategy

- Prefer docs and examples first because they are low-risk and useful to official maintainers.
- Prioritize reproducible GitHub issues around official SDKs and docs mismatches.
- Keep PRs small: README correction, example improvement, type/schema clarification, compatibility note, or test case.
- Use X for build-in-public summaries only after a concrete artifact exists.
- Use Builder Program form only after a stable public website and GitHub URL exist.

## Hard Stops

- Do not post on X without user-confirmed text.
- Do not comment, open issues, submit PRs, create repos, or push to public GitHub without confirmation.
- Do not enter Builder API key, Polymarket API key, wallet signatures, or contact fields into forms without confirmation.
- Do not perform trading, deposits, withdrawals, wallet approvals, fake volume, spoofing, or leaderboard gaming.
