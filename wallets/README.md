# Wallet Storage

Generated Polymarket hot wallets are stored under:

`secure/wallets/`

This directory is ignored by git and wallet files are written with owner-only permissions where the operating system allows it.

Expected wallet label in MetaMask:

`polymarket 开发者钱包`

Do not paste the private key into websites, bots, Discord, Telegram, X, or forms. The official contribution wallet for forms is:
